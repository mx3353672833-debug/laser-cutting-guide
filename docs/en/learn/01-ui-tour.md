## Control panel

![Control panel](../../../assets/screenshots/bochu-cypcut/control-panel.png)

Start cuts. Pause freezes. Stop ends the run and parks the head. Simulate stays on screen. Frame and dry run move the machine with the laser off.

## Coordinates

![Coordinates](../../../assets/screenshots/bochu-cypcut/coordinates.png)

Floating origin sits under the head right now. Work origin sits on a fixed bed point. Home first or the numbers lie.

## Three checks before cutting

![Manual check](../../../assets/screenshots/bochu-cypcut/manual-check.png)

Jog axes. Toggle laser, gas, pointer. See if the machine behaves.

![Preview](../../../assets/screenshots/bochu-cypcut/preview-position.png)

Preview shows head, part, and travel together.

![Frame and dry run](../../../assets/screenshots/bochu-cypcut/frame-border-dryrun.png)

Frame walks the bounding box. Border walks the outer contour. Dry run walks the real toolpath, laser and gas off.

## Technique area

![Technique](../../../assets/screenshots/bochu-cypcut/technique-panel.png)

![Layers](../../../assets/screenshots/bochu-cypcut/layer-cut.png)

Each layer can carry its own cut and pierce settings.

## Alarms

![Alarm](../../../assets/screenshots/bochu-cypcut/alarm-title.png)

Red text means stop. Copy the raw message. Use the [stuck guide](00-stuck.md). Still stuck, stop the machine and hand the text to someone.

## Three-minute drill

Open the software. Point at menus, board, control panel, alarm bar. Find simulate. Do not press start. Write down where start/pause/stop live on your screen.
