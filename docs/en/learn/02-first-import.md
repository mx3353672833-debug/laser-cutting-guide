# 02 Import

[简体中文](../../zh-CN/learn/02-first-import.md) | [English](./02-first-import.md)

You need a PC, the software (demo mode is enough), and [ex01](../../../exercises/dxf/ex01-double-hole-plate.dxf).

## Import

File → Import → ex01.

![Import](../../../assets/screenshots/bochu-cypcut/import-dialog.png)

You want a rectangle and two circles. Empty board goes to the stuck guide.

## Measure

Do it now. Long edge 80, short edge 40.

If you see about 2032, the file was read as inches. Fix units to mm and measure again. Do not touch kerf until the ruler agrees.

## Inner and outer

![Inner and outer](../../../assets/screenshots/bochu-cypcut/inner-outer.png)

Big frame is outer. Two circles are holes. Holes first when cutting.

## Save

Save with a date in the name.

When you can say 80×40 and tell hole from frame, keep going.
