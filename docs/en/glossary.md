# Glossary · 术语表

[简体中文](../zh-CN/glossary.md) | [English](./glossary.md)

| English | 中文 | Notes |
|---|---|---|
| Motion / laser controller (FSCUT…) | 控制系统 | On-machine hardware/firmware |
| Machining software (CypCut family) | 加工软件 | Cutting control on the industrial PC |
| Nesting software (CypNest etc.) | 套料软件 | Layout only; no beam control |
| Document / manual version | 文档版本 | Cover or revision table |
| Software version the manual is based on | 基于软件版本 | Preface statement |
| Runtime version | 运行版本 | About dialog |
| Demo mode | 演示模式 / DEMO | No control card/dog: design only |
| Simulation edition | 仿真版 | Empower wording without dongle |
| Lead-in / lead-out | 引线 | Entry/exit paths |
| Kerf compensation | 割缝补偿 | Offset toolpath by measured kerf |
| Kerf | 割缝 | Actual cut width |
| Micro joint (ordinary) | 微连（普通） | Uncut link against tipping; laser off at point |
| Seamless micro joint | 无痕微连 | Reduced power + root ratio |
| Cooling point | 冷却点 | Corner dwell + laser off + timed gas cool |
| Inner / outer profile | 内模 / 外模 | By enclosure |
| Positive / negative cut | 阳切 / 阴切 | Outer lead from outside / inner from inside |
| Frame / border walk | 走边框 | Walk outer box/contour to check range |
| Dry run | 空走 | Move on toolpath, laser/gas off |
| Homing / return to origin | 回原点 | Build machine coordinates |
| Return to work/program zero | 回零 | Software wording applies |
| Capacitive calibration | 电容标定 | Sensor value vs gap |
| Floating-head calibration | 浮头标定 | M-series menu name |
| Pressure calibration | 气压标定 | DA valve ↔ nozzle pressure (BLT) |
| Edge finding | 寻边 | Plate angle/position |
| Breakpoint resume | 断点续切 | Continue from stop |
| Machining task | 加工任务 | Zero/edge/breakpoint/drawing bundle |
| Supply gauge setting | 供气表设定 | Regulator gauge setting |
| Process gas pressure | 工艺气压 | Depends on stock/power/nozzle |
| Stand-off / nozzle gap | standoff | Nozzle to plate |
| Protective / cover window | 保护镜 | Head protective window |
| First article | 首件 | First trial part + inspection |
| Supervised coaching | 带教 | With a technician who knows this machine |
