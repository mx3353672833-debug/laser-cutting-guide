## 学会什么

把材料、厚度、切割头、喷嘴、气体等条件与**整行**工艺参数对应起来，并准备首件。

## 前置与适用版本

第 07 章。参数来源必须带条件；练习机以**随机工艺表**为准。本地参数库与喷嘴指南仅作条件化参考。

## 1. 读工艺表的条件列

每一行必须能对上：

| 条件 | 为何重要 |
|---|---|
| 激光器型号/功率/芯径/光学配比 | 能量与焦点 |
| 材料与厚度 | 熔化与吹除 |
| 切割头与喷嘴型号/孔径 | 气流对称 |
| 气体 | O2 放热 / N2 高速洁净 |
| 速度、功率、气压、焦点、切高 | 共同决定断面 |

**整行引用**，禁止拆一个气压数字到别的材料。

## 2. 喷嘴参考（不是硬阈值）

GWEIKE 喷嘴选型页给出 S/D/E/B/SP 类型与功率段对照，但页面自称**工程起始参考**，最终以装机切割头与整机工艺表为准，并存在配置例外。  
6 kW / 8 kW 附近有类型切换提示，**不能**写成无例外规则。

standoff 多在 0.5–1.0 mm（勿超约 1.2 mm）等仅作参考量级。

## 3. 供气表 vs 工艺气压

某系列安装资料中的 N2 2.0 MPa / O2 0.8 MPa 是**供气表设定**示例，不是你的连接片工艺气压。

## 4. 首件准备单

1. 材料牌号/厚度实测。  
2. 工艺表匹配行（含头/喷嘴/气体）。  
3. 喷嘴外观与孔径。  
4. 焦点策略（表内 F 值）。  
5. 程序：连接片，内先外后。  
6. 检验工具：卡尺、角尺、照明。

## 练习

1. 为什么参数要整行引用？
2. 喷嘴指南的 6/8 kW 拐点能否直接当硬规则？
3. 给连接片填一张首件准备单（可空着待现场）。

## 答案与评价

1. 条件互锁，拆行会导致工艺错误。
2. 不能；页面为起始参考且有例外。
3. 表结构正确即可。

**评价**：不提供跨机通用气压/速度/功率数字。

## 常见错误

- 从别的功率表抄气压。
- 用供气表设定冒充切割气压。
- 忽略喷嘴型号与孔径。
