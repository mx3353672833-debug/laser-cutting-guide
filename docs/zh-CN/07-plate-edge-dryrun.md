# 07 · 让图纸对准板材

[简体中文](./07-plate-edge-dryrun.md) · [English](../en/07-plate-edge-dryrun.md)

排样在屏幕里没有越过板框，还需要把这张排样放到真实板材上。先处理实际板材、坐标与起始位置，再执行寻边和运动检查。

## 寻边找的是位置和倾斜

板材略有斜放时，只把零点放到一个角，并不能描述另一端的位置。寻边通过板边信息确定位置和角度，让软件知道排样相对板材怎样放置。它不修复错误的图纸尺寸，也不判断切割工艺是否合适。

![经典 CypCut 寻边入口](../../assets/screenshots/bochu-cypcut/find-edge.png)

*官方示例在 CNC 页签中标出 Find Edge。E/Pro 使用各自手册入口。*

## 填参数时，先把板和轴对应起来

![经典 CypCut 寻边设置示例](../../assets/screenshots/bochu-cypcut/find-edge-steps.png)

*先看板材 X/Y 尺寸，再看策略和起始点。图中的数字属于原示例。*

板材 X 尺寸是沿机床 X 轴的长度，Y 同理，不一定对应你站在机器旁看到的“长边、短边”。按实际轴向核对。所引 CypCutE 手册建议尺寸略小于实际寻边板材，但这不是随意缩小的理由：参数仍要与板材和寻边策略匹配。

按该机要求回原点，确认跟随正常，并把起始位置设在板内、头下确有板材的区域。该版手册给出板材倾斜不超过 10° 的条件；不要把它粗略改成“十几度也差不多”。策略、尺寸或起点不清楚时，先停止设置，确认后再执行。

## 寻边后仍要检查排样

观察找到的基准与倾角是否符合眼前的板材，再预览整份路径是否落在可用材料内。若排样中设置过留边，核对寻边留边是否会重复叠加。夹具和损坏板边也属于不可用区域，矩形尺寸并不描述所有障碍。

之后按机器规程执行走边框和空走。开始前就应确认各段路径、头部高度和障碍之间的空间；空走是复核，不是让机器去碰撞来探路。板材被移动、零点被改动或图形重新排样后，要重新做受影响的检查。

本章练习：在纸上画一块倾斜板材，标出机床 X/Y、寻边起点、排样外接框及一处夹具。说明为什么“框在板里”仍不足以证明全程可走。答案是：板内仍可能存在夹具或局部翘起，外接框检查也未遍历全部内部路径。

依据：CypCutE V7.1 §5.2；CypCutPro V1.0.0 §7.4；[柏楚寻边教程](https://www.bochu.com/tutorials/find-sheet-edge-and-rotation-angle/)。
