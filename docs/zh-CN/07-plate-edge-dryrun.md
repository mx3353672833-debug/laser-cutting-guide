# 07 · 装板、寻边、走边框与空走

[简体中文](./07-plate-edge-dryrun.md) | [English](../en/07-plate-edge-dryrun.md)

[上一章 / 回原点、坐标与标定](06-homing-calibration.md) · [下一章 / 读懂工艺表与准备首件](08-process-tables-first-part.md)

## 学会什么

理解装板、寻边、走边框、空走的定位与检查流程，分清屏幕模拟与真实运动。`需带教上机`

## 前置与适用版本

第 06 章。CypCut 教程 Find Edge / Precheck；CypCutPro §6.2、§7.4（倾斜角不宜超过 **10°**）。

## 1. 装板

- 板材放平，支撑齿条承托到位，避免翘板。
- 关好防护（按该机）。
- 确认切割头下方是板材，可正常跟随。

## 2. 寻边

目的：得到板材偏转角与位置，加工时自动校准。

要点：

1. **先回原点**。
2. 板材倾斜 **不宜超过 10°**（CypCut 教程/Pro 手册）。
3. 板材尺寸输入错误存在**扎头风险**，宁可略小于实际并核对。
4. 常见：三点快速；六点利于薄板避齿条；圆盘寻中用于圆板；手动两点记角度。

## 3. 走边框 / 空走

| 动作 | 路径 | 运动 | 激光 | 看什么 |
|---|---|---|---|---|
| 软件模拟 | 刀路显示 | 不动 | 关 | 顺序与形状 |
| Frame 走边框 | 外接矩形/校正框 | **动** | 关（红光） | 红光是否在板内 |
| Border | 最外轮廓 | **动** | 关 | 范围与障碍 |
| Dry Run 空走 | 完整刀路 | **动** | 关，不开气 | 真实运动是否干涉 |

若寻边后再走边框，可能沿**校正后的倾斜框**运动。

## 4. 检查顺序（案例：连接片）

装板 → 回原点 → 寻边 → 走边框（红光在板内）→ 空走（无干涉）→ 空走中可暂停改参再继续（Pro 语境）→ 再准备出光。

## 练习

1. 为什么寻边前要回原点？
2. 倾斜角上限是多少？超了会怎样？
3. 模拟、走边框、空走三者机床是否运动？
4. 板材尺寸填错的风险？

## 答案与评价

1. 校正机械/机床坐标系。
2. 不宜超过 10°；精度变差、校正不可靠。
3. 模拟不动；走边框与空走**动**。
4. 扎头/撞齿条/出板风险。

**评价**：三动作表正确；强调真实运动需带教。

## 常见错误

- 把软件模拟当成空走。
- 红光不在板内仍点开始。
- 尺寸随手填。
