## 学会什么

按具体型号查维护依据，建立自己的维护记录，不越权拆光路。

## 前置与适用版本

第 05 章。维护周期**按切割头/激光器型号分列**，不合成一张通用日历。

## 1. 按来源分列的周期示例

| 周期 | 项目 | 常见来源口径 |
|---|---|---|
| 每日 | 保护镜检查擦拭 | 柏楚切割头保养文 |
| 每 3 个月 | 密封圈更换 | 同上 |
| 每周 | 盖板/保护镜清洁 | RayTools 切割头手册 |
| 每 2–3 个月 | 准直/聚焦镜 | 同上 |
| 每月 | 冷却水及滤芯 | 创鑫激光器手册 |
| 每 3 个月 | 导轨齿条/水箱/线缆 | 迅镭等整机维护文 |
| 按提醒 | 软件保养/润滑 | CypCutPro / 嘉强保养模块 |

**喷嘴寿命没有统一厂商天数**，用判断标准：孔不圆、内壁烧伤、传感器不稳、单侧挂渣、撞机即换。

## 2. 保护镜规格

不同切割头规格不同（例如 BLT421S 与其它型号镜片尺寸不一样）。**按实物型号与安装位置核对**，不写通用值。

## 3. 边界

| 操作员 | 专业人员 |
|---|---|
| 外观检查、记录、更换喷嘴（按头手册） | 拆光路、激光器内部、电气安装 |
| 按软件保养提醒执行润滑点检 | 伺服/平台配置调试 |
| 停机报修 | 总线级排障 |

## 练习

1. 为什么不能给“万能维护日历”？
2. 喷嘴更换看什么？
3. 哪些明显属于专业人员？

## 答案与评价

1. 型号与部件不同。  
2. 判断标准而非寿命天数。  
3. 光路/激光器/电气/伺服调试等。

**评价**：分表引用；不越权。

## 常见错误

- 用 A 头周保周期保 B 头。  
- 自行拆准直聚焦。

- 创鑫/锐科激光器手册（水与滤芯，按型号）
