## 学会什么

知道从哪里开始、哪些能离线练、哪些必须在带教下上机，并填写自己的机器与软件版本卡。

## 前置与适用版本

- 你已了解激光切割原理、主要部件和销售场景。
- 概念主线通用；具体按钮与菜单按 CypCutE（手册基于软件 6.4.2310）与 CypCutPro（软件 7.1.2432.5）分栏标注。
- 练习机型号尚未统一，本教程不绑定单一机床 SOP。

## 学习路线

1. **软件基础（00–04）**：导入图纸 → 检查 → 引线/补偿/微连/冷却点 → 排样排序与模拟。
2. **上机主线（05–10）**：部件与开机前检查 → 回原点与标定 → 装板寻边 → 工艺表与首件 → 中断恢复。
3. **独立作业（11–14）**：异常反馈 → 维护边界 → 三个项目 → 展会演示。
4. **迁移（15）**：柏楚概念如何对照嘉强，哪些必须重学。

**贯穿案例**：一块 80×40 mm、两个 φ8 孔的双孔连接片。后面各章都用它，不换案例。

```text
离线：图纸/工艺准备/模拟          带教上机：开机/标定/寻边/出光/首件
     00 ── 04                         05 ── 10
            \                             /
             13 三个项目 / 14 演示准备
```

## 离线 vs 带教

| 标签 | 含义 |
|---|---|
| `可离线练习` | 无机床、演示模式即可完成 |
| `需带教上机` | 首次必须由熟悉该机的技术人员带教 |
| `待对应机器验证` | 概念可用，按钮/数值须按现场版本核对 |

| 可离线 | 需带教上机 |
|---|---|
| 导入、单位尺寸、优化、引线/补偿/微连/冷却点、图层映射、排样排序、软件模拟 | 开关机、回原点、电容/浮头标定、装板、寻边、走边框真实运动、出光试切、首件检验、断点续切 |

> 看完视频或做完离线练习，不等于能独立操作整机。首次上机请带教。

## 练习

1. 用上面的表填一张自己的版本卡（运行版本可写「未测」）。
2. 各列 3 项可离线、3 项必须上机的内容。
3. 说出贯穿案例的外形与孔大致尺寸（答案在 13 章）。

## 答案与评价

1. 版本卡三类版本分开写即合格。
2. 示例见上表。
3. 外框约 80×40 mm，两个约 φ8 的孔（离线练习几何，上机尺寸以图纸与现场材料为准）。

**评价标准**：版本三分正确；能区分离线与出光动作；不把演示模式说成可加工。

## 常见错误

- 把手册封面版本当成软件运行版本。
- 以为「模拟」会驱动机床或出光。
- 跳过版本卡，直接按别人截图点按钮。
