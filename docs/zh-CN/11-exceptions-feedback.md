# 11 · 从异常现象找到检查入口

[简体中文](./11-exceptions-feedback.md) · [English](../en/11-exceptions-feedback.md)

“切不好”不是一个足够具体的问题。先把异常分成文件问题、定位或运动问题、加工质量问题，再决定看哪一层。一次只改变一个有依据的条件，才知道哪一步真的有效。

## 先保留现场信息

记录工件编号、软件完整版本、报警原文与代码、发生在哪一步、此前改过什么、板材是否移动。照片尽量标清零件方向和缺陷位置。恢复或改参数之前，先保留当前文件和工艺副本。

| 现象 | 第一组核对 | 暂时不要做什么 |
|---|---|---|
| 导入尺寸差一个固定比例 | 文件单位、测量基准、导入行为 | 用补偿修复比例错误 |
| 同一轮廓重复走 | 重复实体、重复导入、目标层与次序 | 直接提高速度掩盖时间变长 |
| 整件偏到一侧 | 零点、坐标方式、板材定位 | 先改原始设计尺寸 |
| 某处切不透 | 配方条件、实际供给、喷嘴与路径位置 | 同时改速度、焦点和气压 |
| 跟随异常或接近碰撞 | 停止动作，保存提示，核对板面和头部状态 | 连续复位或屏蔽保护 |

先查不会改变机器配置的事实：文件是否正确、材料是否一致、喷嘴标签是否对得上、报警原文是什么。涉及电气、光路、运动参数或联锁的问题交给相应技术人员处理。

## 写一条技术人员能用的反馈

“连接片第 2 孔后，外框右边连续挂渣；同批材料，今天更换了喷嘴；文件 P01-r03，工艺行 SS-…，照片右上角已标方向。尚未改焦点和气压。”这段信息比“氮气不行吧？”更有帮助，因为它保留了现象、变化和没有做过的动作。

使用[异常反馈单](../../templates/zh-CN/03-exception-report.md)。可以不知道原因，但要把事实写准确。网络上的现象—原因表是检查线索，不能代替当前机器的诊断。

练习：如果把气压、速度、焦点同时改了，切面变好了，能否认定气压是原因？不能。先保留基准，通过批准的小步试验和记录区分变量。

依据：对应系统报警说明；[柏楚切割常见问题](https://www.bochu.com/pro_information/激光切割常见问题分析及解答/)。
