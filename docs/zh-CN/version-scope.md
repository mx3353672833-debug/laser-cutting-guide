# 版本范围 · Version scope

[简体中文](./version-scope.md) | [English](../en/version-scope.md)

## 三类版本字段

| 字段 | 含义 | 示例 |
|---|---|---|
| 文档/手册版本 | 封面或修订记录 | CypCutE 手册「版本：7.1」 |
| 手册声明的适用软件版本 | 前言「基于…版本」 | CypCutE **6.4.2310** |
| 运行版本 | 练习机「关于」页 | **本教程未安装实测** |

## 已保留的关键更正

1. 普通微连 / 无痕微连 / 冷却点分清。  
2. 供气表压力与工艺气压分清。  
3. DXF 源层名不自带加工属性。  
4. SHEET/NOTE 须核对不加工。  
5. 喷嘴表是带条件参考（有配置例外）。  
6. 嘉强授权分型号。  
7. 演示模式、屏幕模拟、机床空走分清。
