## 学会什么

用样件包、演示脚本、检查表和异常退出方案准备展会/客户现场演示。

## 前置与适用版本

第 09–12 章。**未检索到厂商官方演示指南**，本章为项目自拟 + 待现场验证。

## 1. 演示包

| 项 | 内容 |
|---|---|
| 样件 | 预切连接片、铭牌、多件样各 1+ |
| 程序 | 已验证工艺行 + 图纸 + 备份 U 盘 |
| 材料 | 同牌号厚度板材 |
| 备件 | 喷嘴、保护镜（按该头） |
| 表单 | 检查表、检验记录、应急联系 |
| 安全 | 急停位置、排烟、无关人员隔离 |

## 2. 演示脚本（熟悉且获准的机器）

1. 开机前检查（简述）。  
2. 回原点。  
3. 寻边 → 走边框（红光在板内）。  
4. 空走或软件模拟。  
5. 试切/正式切 1 个样件。  
6. 讲解切面与条件。  
7. 换图再切。  
8. 收尾与记录。

**话术**：不承诺参数通用；说明“这台机器、这块料、这一行工艺”。

## 3. 异常退出方案

- 立即停机场景：异响、报警、烟尘异常、防护失效。  
- 改为讲解样件与录播，不硬撑出光。  
- 留下反馈单字段。

## 练习

1. 列演示包 6 项。  
2. 写 3 句话术边界。  
3. 填 `templates/zh-CN/04-demo-prep.md`。

## 答案与评价

1. 见 §1。  
2. 示例：不承诺通用参数；说明设备/材料/工艺条件；不演示绕过保护。  
3. 表单字段完整。

**评价**：有异常退出方案；无危险表演。

## 常见错误

- 临场改未验证参数。  
- 对围观者开放安全空间。

## 来源

项目自拟；GWEIKE 安装清单安全定性；首件检验原则。
