## 学会什么

完成三个项目的**准备、模拟与检验计划**。上机出光须带教；离线部分可先做完。

## 项目 A · 双孔连接片（贯穿案例）

![ex01](../../assets/previews/zh-CN/ex01-double-hole-plate.png)

*图 13-1 项目 A 预览。*

**任务**

1. 打开 `exercises/dxf/ex01-double-hole-plate.dxf`（80×40，两 φ8 孔，离线几何）。  
2. 检查单位与闭合。  
3. 引线：孔内、框外。  
4. 补偿：按你实测割缝（可先用练习值并标注待实测）。  
5. 非配合边加微连；尖角演示冷却点。  
6. 排序：两孔 → 外框。  
7. 模拟。  
8. 填首件检验计划（不出光也可先填计划）。

**检查**

- 尺寸口述 80×40、2 孔。  
- 内先外后。  
- 微连≠冷却点。  
- 模拟不驱动机床。

## 项目 B · 文字/铭牌

**任务**

1. 外轮廓 + 安装孔 + 文字（如 P-01）。  
2. 文字若只需标记：映射到打标或**不加工**目标层，勿当切割轮廓。  
3. 引线避开文字区域。  
4. 模拟顺序：字/标 → 孔 → 外框（按你工艺）。

**检查**

- 源层 → 映射 → 目标层 → 工艺四步说清。  
- 不把层名 MARK 当自动打标。  
- 给出检验：字高、孔位、外形。

## 项目 C · 多件布局

![ex08](../../assets/previews/zh-CN/ex08-multi-part-layout.png)

*图 13-2 项目 C 预览（3 件单孔 + SHEET）。*

**任务**

1. 打开 ex08。  
2. 排样在 SHEET 内，留边距（现场定）。  
3. SHEET/NOTE 排除加工。  
4. 顺序：各件内孔 → 各件外框。  
5. 模拟零件数=3。

**检查**

- 说“3 件单孔”。  
- 板框不进刀路。  
- 减少空移的件序说明。

## 答案与验收（摘要）

详见 `exercises/answers/zh-CN/`。验收看可观测结果：尺寸与设计相符、找出缺口、模拟顺序正确，不以“理解了”判分。
