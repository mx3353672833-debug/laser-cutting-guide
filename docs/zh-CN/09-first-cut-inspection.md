# 09 · 切第一件，也检查第一件

[简体中文](./09-first-cut-inspection.md) · [English](../en/09-first-cut-inspection.md)

首件的目的，是证明文件、机器状态和工艺在当前材料上共同得到可用结果。因此先做少量试件，检查后再扩大数量，不把整板排满作为第一次尝试。

## 出光前，确认这次切的就是刚检查的文件

核对加工文件名、材料、目标层、工艺行和零点，确认此前的定位与路径检查之后没有再移动板材或改动程序。按本机操作规程开始首件，通过设备允许的观察方式看加工状态。异常时使用规定的停止方式，不在运动区伸手调整材料。

取件前确认机器状态和热工件处理方式符合本机规程。若零件没有分离，先区分是计划中的微连，还是其他位置没有切透；不要用大力掰断掩盖问题。

## 从连接片上测什么

外形量 80 与 40 两个方向，孔径量两个孔，孔距按照图纸要求的方法测量。孔心并不能用卡尺直接夹住：相等圆孔之间测到的内侧间隙还不等于中心距；使用的测量方法及其误差应符合检验要求。

| 实际看到什么 | 先记录什么 | 可以提出的检查方向 |
|---|---|---|
| 外形小，两个孔却大 | 外形与孔径的实测值 | 导入尺寸、补偿方向与割缝依据 |
| 某一角或某一侧局部粗糙 | 缺陷所在边与加工方向 | 局部路径、支撑、工艺与头部状态 |
| 底边挂渣或部分未切透 | 材料、位置、连续还是局部 | 配方匹配、气体供给、喷嘴等 |
| 零件不平 | 变形位置及支撑情况 | 热影响、顺序与支撑条件 |

这些方向帮助你组织检查，不能单凭外观锁定一个参数就开始乱调。
