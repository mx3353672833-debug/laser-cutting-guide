# 03 · 第一次工艺（引线 / 补偿 / 微连 / 冷却点）

[简体中文](./03-first-technique.md) | [English](../../en/learn/03-first-technique.md)

> **结果**：连接片上有了进刀线、刀路有偏移、非配合边有微连、尖角有冷却点标记。

---

## 你只需要做 4 件事

| 做什么 | 在哪点 | 成功长什么样 |
|---|---|---|
| 加引线 | 工艺/引线 | 轮廓外或孔内多一小段线 |
| 割缝补偿 | 工艺/补偿 | 刀路和原图错开半个缝 |
| 加微连 | 工艺/微连 | 轨迹出现缺口 |
| 加冷却点 | 工艺/冷却点 | 轨迹出现实心点 |

## 第 1 步 · 引线

![引线（官方）](../../../assets/screenshots/bochu-cypcut/lead-line.png)

1. 选中**两个孔** → 加引线 → 类型「直线」或「圆弧」，长度先用默认。  
2. 方向：孔从**孔内废料侧**进。  
3. 选中**外框** → 引线从**外侧**进。  
4. **成功**：轮廓旁边多一小段「进刀尾巴」。  
5. **检查**：尾巴不要横穿别的零件。

**为什么**：不在零件边上开孔，避免烧疤。

## 第 2 步 · 割缝补偿

![补偿（官方）](../../../assets/screenshots/bochu-cypcut/kerf-comp.png)

1. 找「割缝补偿 / 补偿」。  
2. 先用软件默认或工艺表里的缝宽（**以后以实测为准**）。  
3. 方向：**外轮廓外扩、内孔内缩**（多数软件可自动区分内外）。  
4. **成功**：刀路线相对原图有偏移。  
5. **检查**：偏移方向反了 → 尺寸会错得更厉害，改方向。

**为什么**：激光烧掉一条缝，不补就外小内大。

## 第 3 步 · 微连（防翘）

![微连（官方）](../../../assets/screenshots/bochu-cypcut/micro-joint.png)

1. 在**外框非装配边**上点 1～2 个微连。  
2. 长度用默认（通常毫米级）。  
3. **成功**：轨迹出现**缺口**，不是实心点。  
4. **检查**：孔上不要加微连（孔要干净）。

**为什么**：零件切通会翘起来撞头；留一点不切断挂在废料框上。

## 第 4 步 · 冷却点（防烧角）← 别和微连搞混

![冷却点（官方）](../../../assets/screenshots/bochu-cypcut/cooling-point.png)

1. 在**外框尖角**上加「冷却点」。  
2. **成功**：轨迹出现**实心点**（微连是缺口）。  
3. **检查**：缺口=微连；实心点=冷却点。

**为什么**：角上热量堆住会烧糊；停一下吹气降温。

| | 标记 | 作用 | 到该点时 |
|---|---|---|---|
| 微连 | 缺口 | 防翘/撞头 | 关光，可能留一小段不切 |
| 冷却点 | 实心点 | 防烧角 | 停留+关光+吹气 |

---

## 自查

- [ ] 引线：孔内、框外  
- [ ] 补偿：外扩内缩  
- [ ] 微连在外框非配合边  
- [ ] 冷却点在尖角，标记是实心点  
- [ ] 能说出微连和冷却点差在哪  

**一句话串联**：引线避疤 → 补偿补缝 → 微连防翘 → 冷却点防烧角。
