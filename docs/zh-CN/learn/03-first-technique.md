# 03 引线、补偿、微连、冷却点

[简体中文](./03-first-technique.md) | [English](../../en/learn/03-first-technique.md)

![工艺面板](../../../assets/screenshots/bochu-cypcut/technique-panel.png)

## 引线

![引线](../../../assets/screenshots/bochu-cypcut/lead-line.png)

两个孔选上，加引线，从孔内进。  
外框选上，引线从外侧进。  
长度先用默认。尾巴别横穿别的件。

## 补偿

![补偿](../../../assets/screenshots/bochu-cypcut/kerf-comp.png)

找割缝补偿。外扩、内缩。  
缝宽先用默认或工艺表里的数，以后用实测。方向反了尺寸会错得更离谱，先查方向再怀疑别的。

## 微连

![微连](../../../assets/screenshots/bochu-cypcut/micro-joint.png)

外框非装配边点一两个。轨迹上是缺口。  
孔上别加。

## 冷却点

![冷却点](../../../assets/screenshots/bochu-cypcut/cooling-point.png)

尖角上加冷却点。轨迹上是实心点。

缺口是微连，实心点是冷却点。微连管翘头，冷却点管烧角。
