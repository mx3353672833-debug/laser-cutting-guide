# 卡住手册（现象 → 去看哪里）

[简体中文](./00-stuck.md) | [English](../../en/learn/00-stuck.md)

> 教程读到这里卡住？按现象查，不用从头再读。

| 现象 | 先看 | 怎么办 |
|---|---|---|
| 导不进 DXF | 文件格式是否 DXF；路径是否有中文怪字符 | 另存标准 DXF 再导 |
| 尺寸差 25.4 倍 | 单位 inch/mm | 改单位后**重新量尺** |
| 尺寸差一点点 | 补偿方向/缝宽 | 量实测缝宽；检查外扩内缩 |
| 有开口/不封闭 | 优化里的合并/开口检查 | 连接端点或合并线 |
| 同一位置切两遍 | 重复线 | 去重复线 |
| 模拟时顺序乱 | 排序 | 先内后外 |
| 找不到微连/冷却点 | 菜单「工艺」或图层工艺 | 对照 03 课官方截图 |
| 不知道机床会不会动 | 对照 01 课表格 | 模拟不动；走边框/空走会动 |
| 软件界面和截图不一样 | CypCut vs E vs Pro | 区域逻辑相同，按钮名以你屏幕为准 |
| 报警红字 | 复制原文 | 停机；查该机手册；别硬切 |
| 上机不敢动手 | 背 05 课 60 秒清单 | 背不全就先别开切 |

还是不行：在 GitHub 开 **Learning question** Issue，写上：哪一课卡住、软件「关于」版本、你看到了什么。
