# 00 · 先懂这一个故事（所以然）

[简体中文](./00-why-this-works.md) | [English](../../en/learn/00-why-this-works.md)

> **目标读者**：完全没摸过软件的人。用手机也能读完。读完你应该能说出：我在电脑上到底在干什么。

---

## 一句话

> 先在电脑里把「形状 → 先切哪 → 从哪进刀 → 缝要让多少 → 别让小件乱飞」想清楚；  
> 再让机器「找到板 → 试着走一圈 → 切第一件 → 量尺寸」。  
> **所有数字都绑着「这块料、这台机、这一行工艺」。**

## 三张图看懂全流程

官方总览（柏楚 CypCut 教程图）：

![CypCut 加工总流程（官方教程图）](../../../assets/screenshots/bochu-cypcut/flow-overview.png)

*图 · 来源：柏楚官方教程 Operation Flow。这就是你电脑上要走完的 6 步。*

用白话说这 6 步：

| 步骤 | 你在干嘛 | 如果跳过会怎样 |
|---|---|---|
| 1 导入图纸 | 把「要切的形状」放进软件 | 没有形状，无从谈起 |
| 2 优化图纸 | 查尺寸、修开口、去重复线 | 尺寸错、同一道线切两遍 |
| 3 工艺设置 | 引线、补偿、微连、冷却点 | 边缘烧糊、尺寸不对、小件飞起撞头 |
| 4 路径规划 | 先切孔还是先切外框 | 先切外框，小片掉下来乱飞 |
| 5 加工前检查 | 模拟 / 走边框 / 空走 | 机床撞板、切出床外 |
| 6 加工控制 | 开始 / 暂停 / 断点 | — |

**模拟 ≠ 空走 ≠ 出光**（初学最容易混）：

| | 机床动吗 | 出光吗 | 干嘛用 |
|---|---|---|---|
| 软件模拟 | 不动 | 否 | 屏幕上看路径顺序 |
| 走边框 / 空走 | **动** | 否 | 看会不会撞、范围对不对 |
| 加工 | 动 | **是** | 真切零件 |

## 为什么要做「引线 / 补偿 / 微连 / 冷却点」

不是软件故意为难你。激光是物理现象，这四个是在**抵消副作用**：

![引线（官方界面）](../../../assets/screenshots/bochu-cypcut/lead-line.png)

**1. 引线（Lead line）**  
从零件**边上**直接开切，起点会烧出疤、起步速度也不稳。  
所以先在**废料区**穿孔，再走进零件轮廓。  
→ 你看到的效果：多了一小段进刀线。

![割缝补偿（官方界面）](../../../assets/screenshots/bochu-cypcut/kerf-comp.png)

**2. 割缝补偿（Kerf）**  
激光会烧掉约一条缝。若刀路正好走在图纸线上：  
- 外轮廓会**小一圈**  
- 内孔会**大一圈**  
所以刀路要往「该留料」的一侧偏大约 **半个缝宽**。缝宽以**实测切口**为准。  
→ 你看到的效果：刀路线和原图不重合，有偏移。

![微连（官方界面）](../../../assets/screenshots/bochu-cypcut/micro-joint.png)

**3. 微连（Micro joint）**  
零件切通后会翘起来、掉下来，可能撞激光头。  
所以故意**留一小段不切断**，让零件还挂在废料框上。  
→ 你看到的效果：轨迹上有缺口标记，零件用手掰下来。

![冷却点（官方界面）](../../../assets/screenshots/bochu-cypcut/cooling-point.png)

**4. 冷却点（Cooling point）** ← **不是微连**  
尖角处热量堆积，容易烧过头、变形。  
走到角上**停一下、关光、吹气冷却**，再继续。  
→ 你看到的效果：轨迹上有实心点标记。

> **记法**：微连 = 防「翘起来撞头」；冷却点 = 防「角上烧糊」。目的完全不同。

## 你现在不需要老师也能做的事

| 能做 | 说明 |
|---|---|
| 读懂界面 | 下一课《认界面》 |
| 装演示模式软件 | 无控制卡也能练设计（见 `version-scope.md`） |
| 导入练习 DXF 并量尺寸 | 完全离线 |
| 设引线/补偿/微连/冷却点并模拟 | 完全离线 |
| 背下上机安全清单 | 下一阶段自己上机前背熟 |

| 需要机器才能验证 | 说明 |
|---|---|
| 真实按钮叫什么 | 各版本界面不同，以你屏幕为准 |
| 回原点/寻边手感 | 每台机不一样 |
| 第一件尺寸 | 和材料、喷嘴、那一行工艺绑在一起 |

**安全底线（不是吓你，是保护机器和你）**：  
出光前必须知道急停在哪；防护没关好不要出光；报警没清不要硬切。这些是**上机时自己遵守的规则**，不是「必须永远有老师在旁边」。
