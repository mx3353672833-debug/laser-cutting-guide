# 02 导图

[简体中文](./02-first-import.md) | [English](../../en/learn/02-first-import.md)

要的东西：电脑、软件（演示模式就行）、[ex01](../../../exercises/dxf/ex01-double-hole-plate.dxf)

## 导入

文件 → 导入，选 ex01。

![导入](../../../assets/screenshots/bochu-cypcut/import-dialog.png)

图板上应该出现一个矩形加两个圆。没有就去看卡住手册。

## 量尺寸

马上量。长边 80，宽边 40。

显示大约 2032 的话，是单位被当成英寸了，差 25.4 倍。先把单位改成毫米再量。这时候别动补偿，先保证读数对。

## 内外

![内外](../../../assets/screenshots/bochu-cypcut/inner-outer.png)

外面大框是外轮廓，里面两个圆是孔。切的时候先孔后框。

## 存

另存，名字带日期。
