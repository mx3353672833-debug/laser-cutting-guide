# 02 · 第一次导图（跟做）

[简体中文](./02-first-import.md) | [English](../../en/learn/02-first-import.md)

> **你要做出的结果**：软件里出现一块 80×40 的连接片，量尺数字正确。  
> 准备：电脑 + 软件（或演示模式）+ [ex01 DXF](../../../exercises/dxf/ex01-double-hole-plate.dxf)

---

## 准备清单

| 要准备什么 | 去哪弄 | 干嘛用 |
|---|---|---|
| 切割软件 | 机器工控机，或本机演示模式 | 导图 |
| ex01 文件 | 本仓库 exercises/dxf/ | 练习 |
| 记事本 | 手机备忘录即可 | 记版本和尺寸 |

## 跟做步骤（点什么 → 看到什么）

### 第 1 步 · 导入

1. 点菜单 **文件 → 导入**（英文 File > Import）。  
2. 选 `ex01-double-hole-plate.dxf`。  
3. **成功**：绘图板上出现矩形 + 两个圆。  
4. **不成功**：什么都没有 → 看卡住手册「导不进」。

![导入对话框（官方）](../../../assets/screenshots/bochu-cypcut/import-dialog.png)

*图 02-1 官方 Import 界面。*

### 第 2 步 · 立刻量尺寸（最重要）

1. 找**测量/量尺**工具（不同版本叫「测量」「尺寸」）。  
2. 点矩形的长边。  
3. **成功**：大约 **80**（单位 mm）。  
4. 再量宽边：大约 **40**。  
5. **失败**：显示约 2032 → 单位被当成 inch 了（×25.4）。去单位/缩放设置改成 mm，再量。**别先改补偿。**

### 第 3 步 · 认孔和框

- 外面的大矩形 = **外轮廓**  
- 里面两个圆 = **内轮廓（孔）**  
- 切的时候**先孔后框**（下一课设顺序）

![内轮廓外轮廓（官方）](../../../assets/screenshots/bochu-cypcut/inner-outer.png)

*图 02-2 内外轮廓识别（官方图）。*

### 第 4 步 · 存盘

文件 → 另存为，名字带日期，例如 `ex01-2026-09-22.lxd` 或软件默认工程格式。
