# 05 · 自己上机（背熟清单再动）

[简体中文](./05-first-on-machine.md) | [English](../../en/learn/05-first-on-machine.md)

> **定位**：多数人是「先看会了，再去机上自己摸」。本课不是「永远要有老师」，而是「**你自己上机时必须遵守的安全清单**」。  
> 每台机按钮不同；**动作顺序以该机 SOP / 机身标识为准**。下面是通用骨架。

---

## 上机前 60 秒背诵（不过就不开切）

1. **急停在哪？**（手能拍到）  
2. **防护门/罩关好了吗？**  
3. **排烟开了吗？**  
4. **水冷/气有没有报警？**  
5. **软件报警栏是不是干净？**  
6. **我不知道的时候就停，不猜按钮。**

---

## 建议第一次上机流程（自己做也能安全）

| 步 | 你做什么 | 成功 | 不成功 |
|---|---|---|---|
| 1 | 按该机顺序上电 | 面板正常 | 停，查 SOP |
| 2 | **回原点** | 坐标建立 | 有报警先清报警 |
| 3 | 手动点动各轴（慢） | 运动方向对 | 立即急停 |
| 4 | 放板、关罩 | 板平、罩好 | — |
| 5 | **寻边**（板斜角别太大） | 得到角度/零点 | 尺寸别填错（会撞） |
| 6 | 走边框 | 红光在板内 | 改位置 |
| 7 | 空走 | 无干涉 | 改图/板 |
| 8 | 用**现场验证过的**工艺行切第一件 | 切透 | 停，记参数 |
| 9 | 量尺寸、记照片 | 有数据 | 不批量 |

## 第一件参数怎么来（别自己发明）

1. 问现场：**这块材料**有没有验证过的工艺行？  
2. 有 → 整行照抄（材料厚度、喷嘴、气体、速度、功率、气压、焦点）。  
3. 没有 → **不要切**，或只在有人给出整行后再试。  
4. 切完把「参数 + 结果」记下来，这才是你的资产。

---

## 出问题时（你自己能做的）

| 现象 | 先做什么 | 别做什么 |
|---|---|---|
| 报警红字 | 停止，抄报警原文 | 疯狂复位继续 |
| 切不透 | 停止，查喷嘴/速度/是否整行抄错 | 无限加气压硬切 |
| 尺寸不对 | 查补偿方向、单位 | 不量就改一堆参数 |
| 异响/撞 | **急停** | 好奇再点开始 |

## 自查

- [ ] 能默写 60 秒清单  
- [ ] 知道回原点、寻边、走边框、空走、出光的顺序  
- [ ] 知道工艺必须整行抄，不自己发明  
- [ ] 知道报警就停  

**一句话串联**：背清单 → 回原点 → 寻边 → 走边框 → 空走 → 整行工艺切第一件 → 量并记录。
