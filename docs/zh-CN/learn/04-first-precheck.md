# 04 检查

[简体中文](./04-first-precheck.md) | [English](../../en/learn/04-first-precheck.md)

## 先排序

孔1 → 孔2 → 外框。  
先切外框，片子掉下来就麻烦了。

## 三个动作

模拟：机床不动。看路径顺序。  
走边框：机床动。看范围在不在板上。  
空走：机床动。看撞不撞。

![边框空走](../../../assets/screenshots/bochu-cypcut/frame-border-dryrun.png)

![预览](../../../assets/screenshots/bochu-cypcut/preview-position.png)

## 电脑上先做模拟

点模拟。顺序要是孔在前框在后。路径应该有三条：两孔加外框。反了回去改排序。

## 有机床再做后两个

板放平，人离开运动区。走边框，看红光在不在板上。空走，听声音，看碰不碰夹具齿条。  
出界或者要撞，停。挪图或挪板。别硬开切。
