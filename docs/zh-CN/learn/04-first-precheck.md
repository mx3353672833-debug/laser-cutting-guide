# 04 · 第一次检查（模拟 / 走边框 / 空走）

[简体中文](./04-first-precheck.md) | [English](../../en/learn/04-first-precheck.md)

> **结果**：路径顺序正确、范围在板内、知道机床会不会动。  
> 本课**可以完全在电脑上做完**。

---

## 先排序（先内后外）

1. 找**排序 / 路径规划**。  
2. 目标顺序：**孔1 → 孔2 → 外框**。  
3. **成功**：顺序号 1、2、3 是孔在前框在后。  
4. **错**：先切外框 → 小片会掉。

---

## 三种检查，别混

| 动作 | 点哪 | 机床 | 你看什么 |
|---|---|---|---|
| 模拟 | 模拟/仿真 | **不动** | 路径形状和顺序 |
| 走边框 Frame | 走边框 | **动** | 红光/轨迹是否在板内 |
| 空走 Dry Run | 空走 | **动** | 会不会撞、范围对不对 |

## 跟做（电脑阶段）

### A. 软件模拟（现在就做）

1. 点**模拟**。  
2. **成功**：看到路径按 1→2→3 走完。  
3. **失败**：顺序反了 → 回排序改。  
4. 数一数：应有 **3** 条轮廓路径（两孔+外框）。

### B. 走边框 / 空走（有机床再做）

1. 确认板放好、人离运动区。  
2. 走边框 → 看红光是否在板内。  
3. 空走 → 听声音、看会不会碰夹具/齿条。  
4. **成功**：范围合理、无干涉。  
5. **失败**：出板或要撞 → **停止**，改图位置或板位置，不要硬开切。

---

## 自查

- [ ] 顺序是孔→框  
- [ ] 模拟机床不动  
- [ ] 能说出走边框和空走机床会动  
- [ ] 模拟里零件数是 3 条路径  

**一句话串联**：先内后外 → 模拟看顺序 → 走边框看范围 → 空走看干涉。
