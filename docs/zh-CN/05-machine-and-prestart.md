# 05 · 从屏幕走到机器：部件与开机前检查

[简体中文](./05-machine-and-prestart.md) | [English](../en/05-machine-and-prestart.md)

## 学会什么

看懂切割头、气路、水路、排烟与运动区域，使用开机前检查表。`需带教上机`

## 前置与适用版本

第 04 章。本章为**部件认识 + 检查原则**。具体开关机按钮与顺序 **`待对应机器验证`**，以该机 SOP 为准。  
**不要**把安装接线手册的首次通电测试改写成日常开机动作。

## 1. 你必须认识的区域

| 区域 | 看什么 | 出问题会怎样 |
|---|---|---|
| 切割头 | 喷嘴、保护镜窗、陶瓷体、跟随后 | 挂渣、功率衰减、跟随异常 |
| 气路 | 供气表设定、工艺气路、喷嘴冷却气是否分开 | 烧嘴、切不透、毛刺 |
| 水路 | 水冷机液位/温度/流量报警 | 结露、过热 |
| 排烟 | 吸尘是否工作、场地通风 | 烟尘危害 |
| 运动区 | 齿条、支撑、行程、急停 | 撞头、撞板 |

## 2. 三个“压力”不要混

| 概念 | 作用位置 | 例子 |
|---|---|---|
| 供气表设定 | 气瓶减压/气表 | 某 M 系列资料：N2 2.0 MPa、O2 0.8 MPa（**供气表语境**） |
| 软件/阀输出设定 | 控制系统气体参数 | 须查该机工艺 |
| 喷嘴处实际气压 | 喷嘴出口 | CypCutPro 气压标定校正 DA 阀与喷嘴处气压（**仅 BLT 头**） |

**禁止**把某系列供气表数字当成所有材料/厚度/功率的通用切割气压。

## 3. 开机前检查记录（原则）

具体动作来自该机 SOP。用 `templates/zh-CN/01-prestart-checklist.md`：

1. 个人防护与急停位置确认。  
2. 排烟/通风开启条件。  
3. 水冷：液位、温度、报警。  
4. 气体：瓶压/空压、泄漏、气表设定（记数值与单位）。  
5. 切割头：喷嘴、保护镜外观。  
6. 床身：支撑齿条、异物、限位外观。  
7. 软件报警栏是否干净。

`可离线练习`：默写检查表结构。`需带教上机`：按 SOP 勾选。

## 4. 贯穿案例

连接片首件前：确认板厚材料 → 气体与喷嘴与工艺表一致 → 保护镜无污染 → 排烟开 → 急停已复位（按该机方式）。

## 练习

1. 画出五个区域并各写一条检查项。
2. 解释供气表设定 ≠ 工艺气压。
3. 哪些检查不通过不能启动？

## 答案与评价

1. 见 §1。  
2. 供气表在气源侧；工艺气压随材料厚度功率与喷嘴变化。  
3. 示例：水冷报警、气体泄漏、排烟未开、急停未复位、限位异常——以该机 SOP 为准。

**评价**：不编造未见过的按钮位置；不把安装通电测试当日常开机。

## 常见错误

- 把 M 系列 2.0/0.8 MPa 写成通用工艺表。
- 跳过保护镜与喷嘴外观。
- 未开排烟就准备出光。
