# 05 · 认识机器的操作条件

[简体中文](./05-machine-and-prestart.md) · [English](../en/05-machine-and-prestart.md)

在电脑上，错误通常表现为图形和路径不对；到机器旁，同一份文件还受到板材支撑、头部状态、气体、冷却和防护条件影响。先沿着“切割头需要什么”认识这台机器，比背一串开关顺序更容易理解。

## 沿着切割头看一圈

光学系统把激光聚焦到加工区域，喷嘴引导辅助气体，陶瓷体与传感部分配合高度检测。板材与喷嘴之间的间隙会随板面变化，跟随系统需要有效的标定关系。保护镜的作用和位置要按具体头型号看，不能凭另一台机器的镜片尺寸采购或更换。

再往外看：冷水机服务于激光器或光学部件的冷却回路，排烟系统处理切割产生的烟尘，气路需要提供对应气体和稳定供给，工作台负责支撑板材。它们各自正常，软件的工艺设置才有意义。

| 你看到的现象 | 它关系到什么 | 先核对的资料或状态 |
|---|---|---|
| 喷嘴口损伤或明显变形 | 气流与头部状态 | 当前喷嘴规格、该头检查方法 |
| 板材架空或局部翘起 | 跟随与运动空间 | 装板和支撑要求 |
| 气体不足或类型不明 | 配方条件是否成立 | 气体标识、供给状态与工艺行 |
| 水冷或排烟异常 | 运行前提是否满足 | 设备状态和整机规程 |

这些是检查入口，不是看到一个现象就能断定唯一故障原因。

## 开机顺序为什么不能从别的机型照搬

整机制造商会把主电源、冷水机、激光器、伺服和辅助设备组织成自己的控制流程。有的动作由柜体开关执行，有的由软件或 PLC 执行。研究资料中的首次安装通电测试，也不等于日常启动程序。

找到这台机器的操作规程，按规程逐项启动，并在每一步确认它应有的就绪状态。不要把“没有红字”当成所有辅助设备都已准备好；排烟是否工作、板材是否支撑好，需要现场检查。

## 实际完成一次开机前核对

使用[开机前记录表](../../templates/zh-CN/01-prestart-checklist.md)，写明机器、软件版本、材料、喷嘴与工艺行。然后核对工作区域没有人员或障碍，防护与联锁正常，正常停止和急停位置明确，冷却、气源、排烟达到本机要求。

先弄清各轴的实际运动方向和允许区域，再按本机规程进行回原点等动作。不要靠手动开激光来“看看机器听不听话”。不了解某一步时，查本机说明或让熟悉设备的人演示这一步，问题解决后继续。

本章完成的标志，是你能把一项检查与它保护的条件对应起来。例如“确认气体类型”是为了保证配方条件成立，而不仅是让表格有一个勾。
