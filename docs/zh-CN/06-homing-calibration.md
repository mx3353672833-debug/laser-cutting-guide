# 06 · 坐标、回原点与标定

[简体中文](./06-homing-calibration.md) · [English](../en/06-homing-calibration.md)

“回原点”“设零点”“标定”听起来都像让机器重新开始，实际上解决的是不同问题。分清它们，才能知道为什么更换喷嘴后需要检查高度，而移动图纸不等于改变机床原点。

## 图纸坐标怎样对应机床坐标

机械坐标是控制系统对机床位置的描述；工件或程序坐标用来确定当前零件放在哪里。回原点按配置建立或校正机械参考，设工件零点则选择加工基准。两者不能互相替代。

例如连接片图纸的左下角为 (0,0)，左孔中心为 (20,20)。若工件原点在机器平面中的位置记作 (X₀,Y₀)，且没有旋转和额外变换，左孔的示意位置就是 (X₀+20,Y₀+20)。寻边修正角度后，关系还包含旋转。这个例子解释了为何图形尺寸没变，换一个零点就能让整件移动。

![经典 CypCut 的坐标选择](../../assets/screenshots/bochu-cypcut/coordinates.png)

*下拉框显示 Floating coordinate 和多个 Workpiece coordinate。它们是坐标工作方式，不是回原点按钮。*

CypCutE 手册的浮动坐标会在执行相应加工检查或加工命令时以当前位置建立程序零点；固定工件坐标则保留设定基准。使用前确认当前方式，特别是点动之后。不要以为“刚刚这里看着对”就意味着下一次仍用同一个基准。

## 标定分别解决什么

| 功能 | 建立或检查的关系 | 本书依据 |
|---|---|---|
| 电容标定 | 传感量与喷嘴到板面距离的关系 | CypCutPro §7.2 |
| 气压标定 | 比例阀控制量与实际出口压力的对应 | 该版 Pro §7.3，仅所述 BLT 条件 |
| 焦点相关检查 | 光学焦点与所用工艺基准 | 对应切割头说明 |

更换喷嘴、陶瓷体或相关部件后，电容测量条件可能改变，应按本机手册规定重新标定或检查跟随。不要因为名字都有“标定”，便顺便改气压或焦点设置。所引 Pro 手册明确说更换喷嘴后无需重做其气压标定；这不取消电容标定的要求。

## 在机器上执行前后分别看什么

执行前确认所选功能和设备匹配，头下板材与周围空间满足该项标定要求，喷嘴/陶瓷体安装状态正常。按对应界面完成后，记录是否成功以及手册要求的结果检查，再确认跟随行为正常。成功提示与实际正常工作应同时成立。

若标定失败，先保存提示和当时条件。不要通过修改传感器参数或屏蔽报警去让结果“变绿”。在坐标未知、头部异常或板面条件不合适时，也不要继续寻边。

小练习：孔位整体偏移但孔距正确，优先查单位缩放还是定位基准？优先查基准与板材定位；缩放通常会连孔距一起改变。这是定位线索，不是排除其他误差的最终诊断。

依据：CypCutE V7.1 §4.1；CypCutPro V1.0.0 §6.1、§7.1–7.3；[经典坐标说明](https://www.bochu.com/tutorials/basics-machining-control/)。
