# 术语表 · Glossary

[简体中文](./glossary.md) | [English](../en/glossary.md)

| 中文 | English | 说明 |
|---|---|---|
| 控制系统 | Motion / laser controller (FSCUT…) | 机床侧硬件与固件 |
| 加工软件 | Machining software (CypCut family) | 工控机上的切割控制软件 |
| 套料软件 | Nesting software (CypNest 等) | 排样，不做出光控制 |
| 文档版本 | Document / manual version | 手册封面或修订记录 |
| 基于软件版本 | Software version the manual is based on | 前言声明 |
| 运行版本 | Runtime version | 「关于」页实际版本 |
| 演示模式 / DEMO | Demo mode | 无控制卡/狗时的设计模式，不能加工控制 |
| 仿真版 | Simulation edition | 嘉强手册中无加密狗时的软件形态 |
| 引线 | Lead-in / lead-out | 进出刀轨迹 |
| 割缝补偿 | Kerf compensation | 按实测割缝偏置刀路 |
| 割缝 | Kerf | 实际切缝宽度 |
| 微连（普通） | Micro joint | 不切割小连接，防零件翘起；到点关光 |
| 无痕微连 | Seamless micro joint | 较小功率出光+留根比例 |
| 冷却点 | Cooling point | 拐角停留关光并延时吹气防烧角 |
| 内模 / 外模 | Inner / outer profile | 按包围关系分层 |
| 阳切 / 阴切 | Positive / negative cut | 外模外引入 / 内模内引入 |
| 走边框 | Frame / border walk | 沿外接框或外轮廓看范围 |
| 空走 | Dry run | 沿刀路运动但不出光不出气 |
| 回原点 | Homing / return to origin | 建立机械坐标系 |
| 回零 | Return to work/program zero | 回到程序零点（用语以软件为准） |
| 电容标定 | Capacitive calibration | 传感器值与头板间距关系 |
| 浮头标定 | Floating-head calibration | 同类标定在 M 系列菜单的叫法 |
| 气压标定 | Pressure calibration | DA 阀电压↔喷嘴处气压（BLT） |
| 寻边 | Edge finding | 求板材偏转与位置 |
| 断点续切 | Breakpoint resume | 从停止点继续 |
| 加工任务 | Machining task | 保存零点/寻边角/断点/图 |
| 供气表设定 | Supply gauge setting | 气源减压表读数设定 |
| 工艺气压 | Process gas pressure | 随材料厚度功率喷嘴变化 |
| standoff | Stand-off / nozzle gap | 喷嘴到板距离 |
| 保护镜 | Protective / cover window | 切割头防护镜片 |
| 首件 | First article | 第一件试切与检验 |
| 带教 | Supervised coaching | 由熟悉该机技术人员陪同 |
