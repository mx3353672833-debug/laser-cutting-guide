## 学会什么

分清可从柏楚复用的概念，与必须在嘉强（RayTools / Empower）重新学习的界面、授权与标定。

## 前置与适用版本

柏楚 03–12 章完成。嘉强按**型号 × 手册版本**区分，不把单一型号授权外推全系。

## 1. 可迁移概念

回原点、电容/浮头标定概念、寻边、走边框、空走、模拟、断点、加工任务、引线、补偿、微连、冷却点、排序、材料/图层工艺。

## 2. 授权与离线（必须分型号）

| 型号/手册 | 原文要点 | 离线 |
|---|---|---|
| XC3000S 用户手册 V1.2 | 须配合加密狗；无狗可开仿真版 | 仿真版 |
| XC3000S 调试手册 V1.4 §3.3 | 激智云扫码 → 机器码与狗号 → 注册码 | — |
| XC3000Plus 调试手册 V1.3 | 修订记录写“1.1 章节去除加密狗标配” | **待核实** |

不要写成“嘉强全系都是加密狗+仿真”。柏楚 DEMO（无控制卡）与嘉强仿真版机制不同，只作对照。

## 3. 型号矩阵措辞

- 以当次官网/图册列出的 XC3000S / Plus / Pro / XC6000 等为准。  
- XC7000：**本轮未找到官方存在证据**（不要写成绝对不存在）。  
- 中英文站当次显示版本号可能不同，未确认分支前不比新旧。

## 4. 必须重学（示例）

1. 标定入口与“重置电容后重标”。  
2. 寻边参数体系（阶跃/留边等）。  
3. 穿孔体系术语（五级/分段/渐进/闪电等）。  
4. 高级工艺（振动抑制、无痕微连、引线工艺）。  
5. XC6000 自整定、多任务等扩展。  
6. 授权与注册。  
7. 导入格式差异。  
8. 界面语言与报警区。

## 5. 概念对照表示例

| 柏楚 | 嘉强（XC3000S 语境） |
|---|---|
| 回原点 | 找原点/回原点 |
| 电容标定 | 电容传感器 → 一键标定 |
| 走边框/空走 | 走边框/空走 |
| 断点继续 | 断点继续 |
| 任务 | 加工任务 |
| 微连/冷却点 | 同名概念（以手册定义为准） |

气压标定在嘉强侧本轮未见与 CypCutPro 同名独立功能——`待对应机器验证`。

## 练习

1. 列 5 个可迁移概念。  
2. Plus 能否沿用 S 的“必须加密狗”表述？  
3. XC7000 该怎么写进教材？

## 答案与评价

1. 见 §1。  
2. 不能；Plus 手册只证明“去除加密狗标配”修订。  
3. “本轮未找到官方存在证据”。

**评价**：授权按型号；措辞不绝对化。

## 常见错误

- 全系统一授权口径。  
- 把中文按钮直译当成已确认英文 UI。
