# 15 · 把柏楚经验带到嘉强

[简体中文](./15-raytools-migration.md) · [English](../en/15-raytools-migration.md)

会用柏楚之后，你已经学会识别图纸问题、判断保留材料、安排引线与顺序、检查首件。这些知识可以带到嘉强。需要重新学的是具体软件怎样表达这些动作，以及这台机器怎样响应。

## 带着同一个零件迁移

仍用 ex01，不急着换复杂图。先确认安装的是哪个 XC 系统与软件版本，再完成导入、测量、图层映射、引线和模拟。用相同的尺寸与路径结果比较，比盲目寻找“和柏楚一样的位置”更有效。

| 已经理解的事情 | 到新系统上重新确认 |
|---|---|
| 图形与加工路径不同 | 几何、工艺与任务的文件格式 |
| 源层要映射到目标层 | 默认映射、最先/最后层及不加工设置 |
| 补偿向废料侧偏 | 输入字段含义、符号、显示方式 |
| 暂停与恢复依赖坐标 | 任务保存、断点定位和继续的条件 |
| 高度与寻边依赖机床状态 | 标定入口、寻边策略、报警处理 |

## 授权也要按型号看

本书采用的 XC3000S 用户手册 V1.2 描述加密狗与无狗仿真版；其调试手册 V1.4 §3.3 描述激智云注册。XC3000Plus 调试手册 V1.3 仅在修订中说明去除加密狗标配，不能据此推断它与 S 完全相同，也不能补出它的完整新授权方式。

关于 XC7000，本轮未找到官方存在证据，不把未检索到写成不存在。选资料时以你屏幕和设备铭牌上的真实型号为准。

## 一次可以完成的迁移练习

制作两列记录：柏楚中这个动作的入口、嘉强对应版本的入口。每完成一个动作，记录相同的结果，例如“80 × 40、两孔 φ8、说明层未加工、先孔后框”。标定、穿孔工艺、任务恢复等不能只凭相似名称就迁移参数，按新系统及整机说明重新确认。

如果只能进入仿真或尚未取得完整授权，完成能做的文件与概念练习，将真实控制测试留在记录中。懂原理会让第二套系统学得快，但不会自动赋予对陌生机器的操作经验。

来源：[嘉强官方下载中心](https://www.empower.cn/download-2/)；XC3000S 用户手册 V1.2、调试手册 V1.4；XC3000Plus 调试手册 V1.3。
